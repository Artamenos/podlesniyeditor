# Портфолио видеомонтажёра

Next.js 16 · React 19 · TypeScript Strict · Tailwind CSS 4 · Lucide React.

## Разработка

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm run check
```

Команда последовательно запускает TypeScript, ESLint и production-сборку.
Настроен статический экспорт: результат сборки находится в `out/`.
Секреты и `.env` исключены из Git. Подготовка GitHub Actions и публикация описаны в [docs/TIMEWEB.md](docs/TIMEWEB.md).

## Языки

- `/` — русская версия, `/en/` — английская. Выбор языка в шапке — выпадающий список с обычными ссылками. Работает в том числе без JavaScript.
- Русское наполнение и общие медиа: `src/data/content.ts`.
- Английские тексты и подписи интерфейса обеих версий: `src/data/translations.ts`.
- При добавлении проектов и отзывов обновляйте обе языковые версии. Видео, постеры, иконки и контакты используются совместно. Субтитры и озвучка автоматически не переводятся.
- Обе страницы заранее создаются при сборке; отдельный сервер перевода и ключи API не нужны.

После `npm run check` выполните `npm run test:export`: проверяются языки HTML, переводы, ссылки переключателя, секции и локальные ресурсы в готовом экспорте.
